# Security Policy

## Supported Versions
Security updates are actively maintained on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability, please report it responsibly rather than opening a public issue.

1. Email vulnerability details or create a private security advisory on GitHub.
2. Include steps to reproduce, environment details, and potential impact.
3. We will acknowledge receipt within 48 hours and work on a fix promptly.
