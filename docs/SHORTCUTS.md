# ⌨️ Mobile Touch Gestures & Keyboard Shortcuts Cheat Sheet

Master navigating your Cloud PC with touchscreen gestures and keyboard shortcuts.

---

## 📱 Mobile Touch Gestures

| Gesture | Action on PC |
| :--- | :--- |
| **Single Tap** | Left Click (Select / Open item) |
| **Long Press (Hold ~1s)** | Right Click (Open Context Menu) |
| **Tap & Drag** | Move window / Select multiple files |
| **Two Finger Tap** | Middle Click / Paste clipboard selection |
| **Two Finger Pinch** | Zoom in / Zoom out |

---

## 🚀 Mobile Quick Bar (Top-Right Screen)

| Button | Function |
| :--- | :--- |
| **`[ ⌨️ Keyboard ]`** | Opens phone's native Gboard / Samsung keyboard |
| **`[ 🔊 Audio ]`** | Toggles live sound streaming to phone speakers |
| **`[ 💬 Type/Paste ]`** | Opens dialog to paste links, code, or type long commands |
| **`[ 🔍 Fit ]`** | Toggles full-screen auto-scaling to fit mobile display |

---

## 🖥️ Linux Desktop Shortcuts

| Shortcut | Action |
| :--- | :--- |
| **`Alt` + `Tab`** | Switch between open application windows |
| **`Ctrl` + `Alt` + `T`** | Open a new Ubuntu Terminal |
| **`Alt` + `F4`** | Close the active window |
| **`Alt` + `F1` / `Super`** | Open the Applications Menu |
| **`Alt` + `F2`** | Run application command prompt |
| **`Ctrl` + `Alt` + `D`** | Show / Hide Desktop |

---

## 💻 Visual Studio Code & Antigravity IDE

| Shortcut | Action |
| :--- | :--- |
| **`Ctrl` + `P`** | Quick Open file search |
| **`Ctrl` + `Shift` + `P`** | Command Palette |
| **`Ctrl` + \`** | Toggle Integrated Terminal |
| **`Ctrl` + `B`** | Toggle Left File Explorer Sidebar |
| **`Ctrl` + `S`** | Save current file |
| **`Ctrl` + `I`** | Antigravity Inline AI Code Lens / Edit |
